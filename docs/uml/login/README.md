# Login Activity Diagram

This folder contains the Sprint 1 UML activity diagram for the Sports Team Management application's authentication flow.

The diagram documents the basic login process, including:

- User credential entry
- Frontend login request
- Backend credential validation
- Missing credential handling
- User lookup and password validation
- Invalid credential handling
- JWT generation
- JWT use for a protected page
- Protected-route JWT validation
- Successful or unsuccessful protected-page access

The editable diagram was created using diagrams.net. A PNG version is also included for easier review.
