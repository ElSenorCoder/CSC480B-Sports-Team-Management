# Sprint 1 Planning Meeting Notes

**Status:** Planned / In Progress
**Sprint Focus:** Project Foundation & Basic Login

## Week 1 Plan

* Establish the initial project architecture, API contract, data model, UML diagrams, and login wireframe.
* Set up the React frontend and create the basic login page, form validation, and protected/dashboard page.
* Set up the Node.js/Express backend with credential validation, JWT generation, authentication middleware, and database connectivity.
* Create the initial SQL database structure, user/role data, seed accounts, and login queries.
* Create authentication test cases and a manual login-testing checklist.
* Document the project setup, Sprint 1 planning decisions, task assignments, and testing results.
* Set up the initial GitHub workflow and basic build/integration checks.

## Week 1 Goal

By the end of the week, the team plans to have a basic end-to-end login flow connecting the React frontend, Express backend, and SQL database. A seeded user should be able to log in, receive a JWT, and access a basic protected page.

Full role-based access control (RBAC), detailed permissions, and complete logout/session behavior will be expanded in Week 2.
