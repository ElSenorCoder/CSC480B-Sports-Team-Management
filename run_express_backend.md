# How to Run the Express Backend

1. Navigate to the backend directory:
   `cd backend`
2. Install dependencies:
   `npm install`
3. Create a `.env` file in the root of the backend folder and define required parameters:
   `PORT=5000`
   `JWT_SECRET=your_jwt_secret_key`
4. Start the server:
   `npm run dev` (or `node server.js`)
5. Verify the backend is active at `http://localhost:5000`.
